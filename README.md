# ⏰ Digital Clock (ساعة رقمية تفاعلية)

ساعة رقمية عصرية ومطورة تציّن الوقت بدقة، مصممة باستخدام تقنيات الويب الحديثة وتدعم نظام 12 ساعة مع أجزاء الثواني.

---

## 🛠️ التقنيات المستعملة (Tech Stack)

- **HTML5:** لبناء الهيكل والعناصر.
- **CSS3 (Flexbox):** للتنسيق، التصميم العصري، والتوسيط.
- **TypeScript / JavaScript:** للمنطق البرمجي، جلب الوقت الفعلي، وتحديث الشاشة تلقائياً عبر `setInterval`.
